Apogee

Trim the Apogee-7 probe's flight software one Arm Cortex-M4 listing at a time. Every byte you save is mass the probe doesn't have to lift.

Every listing is real output from the GNU Arm Embedded Toolchain, arm-none-eabi-gcc 13.2.1, with -mcpu=cortex-m4 -mthumb -Os. Literal-pool loads are shown as ldr rX, =symbol and comments are added; nothing else is changed. The C++ side compiles to the same bytes as C++23, and to the same instructions in C++26 mode (checked with Clang 18). Run build.sh in the repository to regenerate every number.

Level categories follow Kestrel-1. Progress is saved in this browser.
